# 拍立得运行时拖拽

## 行为

实际 Codex 首页中的整张拍立得支持鼠标、触控笔和触摸拖拽。按下后使用 Pointer Capture 持续接收移动事件，释放或取消时结束拖动。

- 拖动只改变拍立得位置 `x/y`，不会改变宽度、旋转角度、围栏或隐藏阈值。
- 位置被限制在当前主题内容区域内，避免拍立得被完全移出可见区域。
- 拖动期间使用页面内状态和内联位置立即更新画面。
- 拖动结果只在当前 Codex 页面生命周期内有效，不写回主题文件，也不通知 Studio。
- 其他 Codex 页面不会同步这次临时位置；重新注入、刷新或重启后恢复到 Studio 中保存的位置。

## 数据流

1. Studio 保存主题时，将拍立得的标准化 `x/y` 位置编译进运行时载荷。
2. 注入脚本以该位置初始化每个 Codex 页面，并在当前页面内维护临时拖拽位置。
3. 拖动结束时只结束 Pointer Capture，不创建预览更新消息，不调用主进程，也不修改磁盘上的主题。
4. 再次注入主题时，页面重新使用 Studio 最近一次保存的位置。

## 隐私约束

运行时拖拽不向 Studio 或主进程发送位置消息，也不读取或传输项目、任务、账号、团队、邮箱或路径信息。实现、测试和验收继续遵守 [隐私与示例数据约束](PRIVACY.md)。

## 验证

当前回归由 `tests/renderer-home-dom.test.ts` 覆盖，验证 Pointer Capture、边界限制，以及拖动拍立得时不会创建 Studio 预览更新。Studio 侧的位置编辑和布局约束继续由拍立得预览、几何及主题测试覆盖。
