# Codex Dream Skin Studio v1.1.0 - macOS Universal & Cross-Platform Reliability

## Highlights

- Added macOS 12+ Universal support for Apple Silicon and Intel Macs, including verified Codex detection, secure launch, configuration backup and recovery, platform-aware Studio controls, and DMG/ZIP packaging.
- Unified Windows and macOS platform drivers and shared theme resources so themes can be edited, imported, exported, and applied consistently across both supported platforms.
- Hardened multi-installation identity checks, session generation tracking, rollback behavior, restart outcomes, backup archive reporting, and backup availability handling.
- Added a video transcoding dialog with source inspection, keep/convert/optimize decisions, output size selection, progress reporting, cancellation, and safe cleanup of pending selections.
- Made theme switching, saving, duplication, deletion, and media imports cancellable and race-safe while preserving the active theme when preparation or activation fails.
- Added video compatibility preflight, GIF poster frames, and system reduced-motion support for animated preview assets.
- Improved CDP cleanup and reinjection recovery, and fixed conversation bubble sizing and layering, New Task navigation state, and cancelled asset preview imports.

## Downloads

- **Windows 10/11 x64:** use `Codex-Dream-Skin-Studio-Setup-1.1.0.exe`. The matching blockmap and `latest.yml` are included for the installed Windows updater.
- **macOS 12+ Universal:** use the DMG or ZIP package on either Apple Silicon or Intel Macs.

This is the first release that publishes supported Windows and macOS downloads together. The macOS build remains unsigned and unnotarized, so first launch may require Finder's **Open** command or approval in **System Settings > Privacy & Security**. macOS updates remain manual.
