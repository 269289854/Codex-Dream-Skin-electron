# Codex Dream Skin Studio v1.1.23 - Independent Project Context Icons and Bubble Controls

- Added independent theme icon configuration for the project, environment, and branch controls in the Codex home composer.
- Added four-corner conversation bubble decorations with independent corner assets, padding, and geometry controls.
- Improved runtime rendering, theme migration, preview editing, and theme sharing for the new appearance settings.
- Fixed plan card click-layer styling and expanded DOM, geometry, IPC, profile, sharing, and runtime regression coverage.

The Windows package is an x64 NSIS installer. The macOS packages are Universal DMG and ZIP builds and remain unsigned and unnotarized. The Windows installer includes its matching blockmap and `latest.yml` for the updater.
