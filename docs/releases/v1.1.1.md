# Codex Dream Skin Studio v1.1.1 - Multilingual Studio & Reliable Video Themes

## Highlights

- Added complete Simplified Chinese and English localization across the Studio interface, theme controls, previews, status messages, errors, Codex operations, and update flows.
- Added typed localized messages and language-aware IPC contracts so the main, preload, and renderer processes present a consistent language throughout long-running operations and failures.
- Added theme video compatibility inspection during import, share-package validation, installation, and launch. Incompatible videos now produce actionable warnings and are blocked before they can reach the Codex runtime.
- Added a managed Studio media protocol for reliable local theme-video previews, including coordinated stream shutdown while themes are deleted.
- Fixed original and optimized video variant creation, preservation, activation, and switching, including correct disabled states in the video controls.
- Improved video export validation so shared themes retain complete variant metadata and portable runtime media.
- Fixed localized notification and error handling across asynchronous Studio operations.

## Downloads

- **Windows 10/11 x64:** use `Codex-Dream-Skin-Studio-Setup-1.1.1.exe`. The matching blockmap and `latest.yml` are included for the installed Windows updater.
- **macOS 12+ Universal:** use the DMG or ZIP package on either Apple Silicon or Intel Macs.

The macOS build remains unsigned and unnotarized, so first launch may require Finder's **Open** command or approval in **System Settings > Privacy & Security**. macOS updates remain manual.
