# Codex Dream Skin Studio v1.1.21 - Runtime Layering and Icon Improvements

- Added protected built-in and custom icon libraries with portable `.cdsicons` import and export.
- Added project and session marker icons with deterministic random assignment and refreshed Codex project discovery.
- Improved home preview sizing, project/session row alignment, streaming assistant bubble detection, and background layer ordering.
- Fixed particle and conversation bubble stacking so decorative effects stay behind readable content.
- Fixed the current Codex home composer integration. The decorative frame, badge, melody, and composer controls now attach to the inner input surface instead of wrapping the credit and project controls.

The Windows package is an x64 NSIS installer. The macOS packages are Universal DMG and ZIP builds and remain unsigned and unnotarized. The Windows installer includes its matching blockmap and `latest.yml` for the updater.
