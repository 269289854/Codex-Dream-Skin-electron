# 使用指南

## 环境要求

- Windows 10/11 x64，以及 Microsoft Store 安装的官方 Codex 桌面应用。
- macOS 12 或更新版本，支持 Intel 与 Apple Silicon；官方 Codex 必须通过 `com.openai.codex` 和 OpenAI Team ID `2DC432GLL2` 验证。
- 安装版不要求单独安装 Node.js；开发构建需要 Node.js 22 或更新版本。

## 安装

Windows 使用 `Codex Dream Skin Studio Setup.exe`。macOS 可以从 DMG 将应用拖入“应用程序”，也可以解压 ZIP 后移动应用。macOS 构建当前未签名，首次打开时应在 Finder 中右键应用并选择“打开”；如果系统仍阻止启动，在“系统设置 → 隐私与安全性”中确认“仍要打开”。不要执行全局关闭 Gatekeeper 的命令，也不要修改官方 Codex 应用包、签名或隔离属性。

## 语言

Studio 界面支持简体中文（`zh-CN`）和英文（`en-US`），选择结果会保存在本机。界面语言与主题的“内容语言”相互独立：切换界面语言只改变 Studio 的按钮、状态和错误提示，切换内容语言则决定当前正在预览和编辑哪一套首页、品牌及侧栏文案。

每个主题会同时保存中文和英文文案。编辑其中一种语言不会覆盖另一种语言；保存、复制、导出和导入主题时两套文案都会保留。主题注入后，Codex 页面会根据自身当前界面语言选择对应文案，并在 Codex 的语言发生变化时更新显示。

## 制作主题

左侧用于创建、复制、删除和切换主题。内置的系统主题会固定标记为“系统主题”，可以修改、复制和导出，但不能删除；新建、复制及分享导入的主题均标记为“自定义主题”，可以正常删除。内置系统预设仅在首次安装或系统主题丢失时创建，软件升级不会覆盖用户已经修改的系统主题；在系统主题中点击“恢复默认”会重新载入完整的内置主视觉、拍立得和雨落特效，点击“保存主题”后正式写入。中间是按照 Codex 当前布局制作的实时预览，右侧用于编辑当前主题。

在“视觉设计”中选择主视觉媒体，并使用缩放、水平位置和垂直位置调整背景。选择媒体后可单独开启“水平翻转”或“垂直翻转”，翻转只影响图片内容，不会镜像首页文字和操作卡片。支持 PNG、WebP、JPEG、SVG、原生 GIF、MP4 和 WebM；SVG 会先校验并转换为 PNG。GIF 最大 30 MB；视频最长边不能超过 4096px，视频不设固定文件大小上限，但导入、复制和分享时必须保留至少 10 GB 或磁盘 15% 的可用空间。媒体会复制到当前平台的 Studio 数据目录，删除原始文件不会影响已经保存的主题。

选择视频后，Studio 会先检查分辨率、帧率、编码、像素格式、音轨和预计负载，再显示导入对话框：

- “兼容”且负载较低的视频默认可以“原样导入”，也可以转换后使用。
- “高负载”视频仍可保留原始版本，但建议按需要降低分辨率、帧率或码率并生成优化版。
- “需转换”的视频不能原样导入，必须转换为可跨平台使用的 H.264/AAC MP4。
- 转换设置支持源尺寸、常用分辨率或自定义尺寸，源帧率、常用帧率或自定义帧率，以及自动或指定视频码率；输出尺寸不能放大源视频，最长边仍不能超过 4096px。

转换期间可以取消操作。取消、关闭对话框、切换主题或选择过期时，Studio 会放弃相应临时选择并清理未提交文件，不会替换当前主题素材。转换完成后会复检输出；失败时保留原主题和已有素材。

兼容视频可以同时保留原始版和优化版，并在视频设置中切换当前使用版本或重新生成优化版。导出分享文件、安装配置和启动主题前会再次检查当前引用的视频；不兼容或缺少可移植版本的视频会阻止继续操作，并提示先转换或切换版本。

视频的自动播放、循环、声音和音量在预览配置页设置。默认自动播放、循环和静音；主视觉与拍立得最多一个位置可以开启声音。浏览器阻止自动播放时会保留画面并显示播放按钮。GIF 遵循文件自身的动画和循环行为，不显示视频播放或声音控件。

“视觉设计”顶部的“整个窗口背景”控制 Codex 完整应用视口，包括顶部工具栏、左侧栏和右侧主区域。背景固定在窗口中，不会随首页/会话切换或内容滚动。颜色模式可以使用纯色、线性渐变或径向渐变；线性渐变支持角度，径向渐变支持中心位置，两种渐变都支持 2–8 个色标。媒体模式支持 PNG、WebP、JPEG、原生 GIF、MP4 和 WebM，并可调整透明度、焦点、缩放及水平/垂直翻转。窗口背景视频始终静音、自动播放、循环并使用内联播放。

启用整个窗口背景后，Studio 预览和实际 Codex 会自动把顶部工具栏、侧栏、主区域、品牌栏等结构表面设为透明，让窗口背景透出；卡片、消息、输入框、边框和装饰仍使用各自的主题样式。关闭整个窗口背景后，这些结构表面恢复原有配置，不会丢失用户设置。

窗口背景可以添加最多 8 层遮罩。图层列表从上到下按“前景到背景”排列，“上移”会使遮罩更靠前；重叠区域按各层透明度正常合成。每层可以独立显示或隐藏、复制、删除和排序，并设置纯色/渐变、透明度、全屏/椭圆/圆角矩形、位置、宽高、边缘柔化和圆角。删除全部遮罩即为“无遮罩”。窗口背景遮罩位于应用内容下方，不会挡住文字、按钮或窗口控制。

窗口背景与“对话区域背景”独立保存。会话背景启用时显示在窗口背景上方；关闭会话背景时，对话区域会透出整个窗口背景。切换任一背景的颜色、图片、GIF 或视频不会清除另一套背景和遮罩设置。

切换到中间预览的会话页面后，可以直接点击对话区域打开“对话区域背景”设置。背景支持纯色、PNG/WebP/JPEG 图片、原生 GIF、MP4 和 WebM，并可单独调整背景透明度、媒体焦点和缩放。背景遮罩支持纯色、线性渐变和径向渐变；线性渐变可调整角度，径向渐变可调整中心，渐变可以添加 2–8 个色标并分别设置颜色与位置。

遮罩形状可以选择全屏、椭圆或圆角矩形。椭圆和圆角矩形只在形状内部着色，形状外保留原背景；可以调整水平/垂直位置、宽度、高度和边缘柔化，圆角矩形还可以调整圆角。切换背景媒体类型不会清除遮罩配置。保存主题并重新注入后，Studio 预览与 Codex 会使用相同的渐变和几何参数。

“会话与按钮”中的“显示聊天气泡”默认开启。可以分别编辑“我的消息”和“Codex 回复”的普通及悬停背景，两类背景都支持纯色、线性渐变、径向渐变和 2–8 个色标；也可以直接在会话预览中点击对应消息快速配置。气泡只包裹用户消息和 Codex 自然语言正文，命令结果、工具卡片、附件及文件差异卡片仍显示在气泡之外。关闭开关后会恢复 Codex 原有消息布局，但不会删除已经保存的两套配色。

聊天气泡装饰可以分别应用到“我的消息”“Codex 回复”和“计划”三种角色。八套内置预设使用 CSS 主体与四张独立角饰分层绘制，气泡宽度或高度变化时角饰保持原比例，不会随正文拉伸。自定义模式必须为左上、右上、右下和左下四个位置分别选择静态 PNG 或 WebP；每张图片最长边不能超过 2048px，四周必须保留透明安全边距，四张合计不能超过 10 MB。四张素材齐全后才能应用，可以继续调整角饰大小、外移量、边框颜色和宽度、圆角及内容边距；自定义气泡主体的普通和悬停填充沿用对应角色的消息背景设置。取消编辑会清理本次新导入且尚未应用的角饰，不改变当前主题。

“首页文案”可以配置首页标题和副标题。标题必须且只能保留一个 `{project}`，注入后该占位符会显示为 Codex 原生项目选择器；副标题留空时不显示。中间预览使用固定的 `1280 × 820` Codex 画布并等比缩放，标题、四张快捷卡片、项目栏、输入框和拍立得与实际注入共用同一套布局样式。

拍立得使用单独的媒体设置。拍立得也有独立的水平/垂直翻转开关；翻转只作用于裁剪区域中的图片、GIF 或视频，相框、裁剪围栏、阴影、图钉、旋转和拖动位置保持不变：

1. 点击“选择拍立得媒体”。
2. 点击指针按钮后，依次选择拍立得的四个角点。
3. 拖动编号角点进行修正，围栏不能自交或超出图片。
4. 在中间预览中直接拖动拍立得，并在右侧调整宽度、旋转和隐藏阈值。
5. 点击“保存主题”。

四点坐标相对原图归一化保存，因此更换显示器或窗口尺寸不会改变原图中的裁切位置。

Studio 中保存的拍立得位置是每次注入的初始位置。主题注入到 Codex 后，用户可以直接在 Codex 页面内拖动拍立得；这个临时位置只在当前页面生命周期内生效，不会写回主题，也不会同步到 Studio 预览。重新注入或重启 Codex 后会恢复到 Studio 中保存的位置。

## 项目图标与素材库

顶部工作区分为“主题编辑”“项目图标”和“素材库”三个页面。Studio 始终提供一套不可删除、不可改名的系统素材库；系统图标使用 `icon/` 中的固定颜色 Pastel SVG，Studio 预览与 Codex 运行时显示同一份资源，不跟随主题颜色变化。用户可以创建多个自定义素材库，并导入 PNG、WebP、JPEG、GIF 或 SVG；用户导入的 SVG 会先执行安全校验再转换为 PNG，GIF 会校验尺寸和动画数据。单个素材库最多 128 个图标，单个文件最多 30 MB。

每个自定义图标都可以设置是否“参与随机”和 `1–10` 的默认优先级。每个主题再独立选择参与随机的素材库，并可覆盖某个图标的开关和优先级；数值越高，在无放回分配中越早被选中的相对概率越高。缓存项目之间的随机图标不会重复；同一项目下的随机会话图标也不会重复，并排除项目最终使用的图标。不同项目的会话可以复用素材。手动指定始终优先且允许重复，随机分配会避开同一作用域内已经手动占用的素材。候选素材用尽后，剩余项目或会话保留 Codex 默认图标，不会为了填满而重复素材。

随机结果和候选池指纹只缓存在本机。同一主题新增项目或会话时，Studio 会保留仍有效的旧结果，只为新对象补充分配；修改启用素材库、参与随机状态、素材内容或优先级后会按新候选池重新分配。复制主题会复制手动项目和会话分配，但派生随机缓存会清空，由新主题使用自己的种子生成。

“项目图标”页只从当前已验证的 Codex 页面刷新项目及会话信息，并在本机保留最近发现记录，离线时仍可配置。刷新时 Studio 会临时展开原本折叠的项目及其完整会话列表，读取完成后恢复 Codex 原来的展开状态。若项目原本已展开且当前 Codex 只提供单向“查看全部”控件，Studio 为避免永久改变侧栏状态，只读取当前可见会话；此前缓存和手动分配仍会保留。Studio 中的项目行可以独立展开，会话图标通过同一素材选择器配置；搜索会同时匹配项目和会话标题。默认开启的“显示会话图标”全局开关只控制 Codex 侧边栏显示，不会禁用 Studio 中的配置。随机素材不足时，对应行会显示“随机素材已用尽 · Codex 默认图标”。项目和会话 ID、显示名称、会话标题、最近发现缓存、随机分配缓存及手动分配均属于本机隐私数据，不会进入主题或素材库分享包。配置更新后对运行中的 Codex 执行“重新注入”即可生效。

主题编辑器原有的图标选择器会显示当前主题已启用素材库中的图标。选择系统图标时仍保存内置图标名称，运行时会把对应的 Pastel SVG 作为图片注入 Codex；选择自定义素材时，主进程会验证并复制一份到当前主题的 `assets/`，使主题槽位继续自包含。只有在内置 SVG 资源缺失时才回退到 Lucide 或 glyph。未主动指定的槽位保持原有系统默认图标。图标选择或主题保存后，运行中的 Codex 需要点击“重新注入”才能看到最新图标。

在“素材库”页可以独立导出非空自定义库为 `.cdsicons`，也可以通过按钮或拖放导入。导入始终创建新的本地素材库并重新生成素材库和图标 ID，不会覆盖现有库。系统素材库不能删除或导出。`.cdsicons` 使用流式 ZIP、SHA-256、路径、条目数量、压缩/解压大小、MIME、文件头和图片尺寸校验；取消、校验失败或磁盘空间不足时不会留下半个素材库。

## 分享主题

左侧主题操作区的下载按钮会打开导出选项，把当前预览中的设计（包括尚未保存的修改）导出为单个 `.cdstheme` 文件。默认可以附带当前主题启用的非空自定义素材库、素材库启用状态和图标优先级；取消勾选时导出兼容旧版本的普通主题包。文件选择器中的上传按钮可以导入分享文件，也可以直接把 `.cdstheme` 拖到 Studio 窗口的释放区域。导入成功后会创建一个新的本地主题并自动激活、打开；不会覆盖已有主题，同名主题也可以并存。

普通分享文件是自包含 ZIP64 包，包含主题配置、实际引用的图片、GIF、视频、定制图标和字体，因此接收方不需要原始素材文件。包含素材库时使用版本 3 组合包：内嵌一个经过相同完整校验的主题包，以及每个素材库对应的独立 `.cdsicons`；导入会为主题、素材库和图标重新生成 ID，并重映射启用与优先级设置。旧版 v1/v2 `.cdstheme` 继续兼容导入。

主题 schema v30 会保留 v29 中选择的内置聊天气泡预设，并自动切换到新的四角分层素材。v29 及更早版本保存的单张自定义气泡图片或 GIF 无法可靠拆分为四角，因此迁移后会变为“无装饰”，其他气泡背景和主题设置保持不变。导入旧 `.cdstheme` 时，Studio 会先按包内原版本完成素材安全校验，再执行迁移；不再被 v30 主题引用的旧气泡素材不会发布到新主题目录或再次导出。

项目与会话列表、ID、显示名称、会话标题、最近发现缓存、候选池指纹、随机分配缓存、全局会话图标开关和手动图标分配绝不会写入 `.cdstheme`。导入前应用会校验文件清单、路径、主题和素材库 schema、素材大小、媒体头部和 SHA-256；不接受脚本或可执行文件。分享导入按流式方式处理并受可用磁盘空间保护，普通主题条目最多 128 个，单个图片/GIF 最多 30 MB、字体最多 12 MB。组合包中任一主题或素材库失败时会回滚本次已经创建的主题和素材库，当前已有数据保持不变。

`.cdstheme` 是跨平台格式：Windows 导出的文件可以在 macOS 导入，macOS 导出的文件也可以在 Windows 导入。包内条目固定使用 `/` 分隔，不允许反斜杠、盘符、绝对路径或路径穿越，主题 JSON 也不会记录源机器的数据根目录。两个平台使用相同主题 schema；包内字体和媒体会随主题复制，不依赖导出机器上的原始文件。

Studio 通过受限的 `studio-media:` 协议预览当前主题实际引用的视频，并只提供播放所需的受限 Range 请求；渲染进程不会获得真实磁盘路径。删除主题前会先关闭该主题的活动媒体流。

视频在 Codex 页面内通过已验证的主题文件绑定生成 `blob:` 地址，不会关闭 Codex CSP。主题运行期间关闭 Studio 窗口会驻留系统托盘，停止主题后释放媒体绑定。

## 图标和颜色

“图标样式”提供品牌、主卡片、副卡片、输入框、项目、装饰和拍立得图钉槽位。每个槽位可选择当前主题素材库中的系统或自定义图标，也可以直接导入 PNG、WebP、JPG、GIF、SVG。系统图标是固定颜色的内置 SVG；用户导入的 SVG 会先检查外部引用和脚本，再转换为 PNG，二者的资源处理方式不同。

颜色设置包含背景、正文、强调、粉色、淡紫、边框、成功和危险状态色。保存后重新注入即可应用到运行中的 Codex。

## 启动和恢复

“运行设置”包含以下操作：

- “检测 Codex”：只读检查当前平台的官方安装身份、版本和运行状态。
- “安装配置”：备份并设置 Codex 的浅色基础主题。
- “启动并应用”：必要时确认重启 Codex，随后开启仅监听回环地址的 CDP 端口并注入主题。
- “重新注入”：保存主题后刷新运行中的 Codex 页面。
- “验证主题”：检查所有 Codex 页面是否存在主题标记和样式。
- “停止注入”：移除当前页面主题，但不恢复基础配置。
- “恢复并重启 Codex”：恢复安装前的配置，归档备份并以普通模式重启 Codex。

主题注入成功后，“Codex 控制”会显示“退出 Studio”。该操作只退出编辑器并保留当前已注入主题，不会停止注入或恢复 Codex；退出后 Studio 不再负责新页面的重新注入。主题活动时直接关闭 Studio 窗口仍会隐藏到系统托盘，托盘中可以选择“退出 Studio（保留当前主题）”或“恢复 Codex 并退出”。

## 数据和安全

应用数据位置：

- Windows：`%LOCALAPPDATA%\CodexDreamSkinStudio`。
- macOS：`~/Library/Application Support/CodexDreamSkinStudio`。

两个平台使用相同目录结构：

- `themes/<id>/theme.json`：主题配置。
- `themes/<id>/assets/`：导入素材。
- `icon-libraries/<id>/library.json` 与 `assets/`：用户自建素材库和经过校验的图标副本。
- `project-icons.json`：每个主题的素材库启用、优先级、项目与会话缓存、候选池指纹、随机分配缓存、全局会话图标开关及手动分配；只保存在本机且不参与分享。
- `backups/`：Codex 配置备份和恢复归档。
- `runtime/`：当前注入载荷和会话状态。

Windows 通过 Store 安装身份和官方进程校验 Codex。macOS 会从标准安装位置和 Launch Services 候选中查找应用，并校验 bundle ID、Team ID、`codesign --verify --deep --strict`、主可执行文件及真实路径。启动调试会话时只使用参数数组调用系统工具；停止时只终止身份、路径和启动时间均匹配的主进程，先发送 `SIGTERM`，超时后才对同一进程发送 `SIGKILL`。

CDP 会校验回环监听、端口所有权、进程签名、浏览器 ID、页面 ID 和 `app://` 页面目标；macOS 仅接受 `127.0.0.1`，并在 `9335–9435` 中选择安全空闲端口。渲染进程不能直接访问文件系统、PowerShell、系统工具或任意 CDP 地址。

macOS 的官方 Codex 配置位于 `~/.codex/config.toml`。Studio 在首次修改前创建备份，只改三个外观键，并使用严格 UTF-8、并发修改检测、同目录临时文件、fsync、原子替换和失败回滚。执行“恢复并重启 Codex”时只恢复本次作用域内的更改，并将已使用备份归档；不要手工删除 `backups/` 或直接覆盖配置。

## 应用更新

只有 Windows 正式安装版启用自动更新。开发模式、unpacked 目录构建和 macOS 构建都不会检查或下载更新，并在“运行设置”中显示更新不可用。macOS 用户需要从可信发布页手动下载新版本并替换 Studio 应用；主题、素材、备份和分享格式不受影响。

## 故障排查

- Windows 检测不到 Codex：确认安装的是 Microsoft Store 官方版本，然后重启 Studio。
- macOS 检测不到 Codex：确认应用位于标准安装位置或已被 Launch Services 登记，并且官方签名、bundle ID 和 Team ID 未被修改。
- macOS 无法首次打开 Studio：使用 Finder 右键“打开”，或在“系统设置 → 隐私与安全性”中确认“仍要打开”；不要全局关闭 Gatekeeper。
- 端口被占用：关闭占用调试端口的程序后重试；macOS 会在安全端口范围内自动选择空闲端口。
- 主题没有出现：打开“运行设置”执行“重新注入”和“验证主题”。
- Studio 意外退出：重新打开后会尝试恢复活动会话；也可以执行“恢复并重启 Codex”。
- 配置错误：不要手工删除 `backups/`，先使用 GUI 恢复。
