# 隐私与示例数据约束

本仓库是公开项目。源码、测试、文档、日志和可提交的图片中不得出现任何开发者本机或真实 Codex 环境的数据。

## 强制规则

- 禁止提交真实项目名、仓库名、任务标题、分支名、工作区名称或未公开的业务描述。
- 禁止提交真实账号名、团队名、邮箱、头像标识、组织名称、用户 ID 或其他身份信息。
- 禁止提交用户目录、绝对文件路径、访问令牌、调试会话信息或包含这些内容的日志。
- 禁止提交未经脱敏的 Codex、Studio 或桌面截图；视觉验收图片必须只显示虚构示例数据，并在提交前人工复核。
- 预览和测试只能使用当前公开仓库名，或明显虚构、与真实本机环境无关的示例名称。
- 不得为了提高预览真实性而从运行中的 Codex 同步项目、任务、账号或团队数据。

## 项目与会话图标隐私边界

- Studio 只从经过进程、页面目标和本机 CDP 端点验证的 Codex 页面读取项目 ID、显示名称、类型，以及会话 ID 和标题，用于“项目图标”页；不会读取项目文件或会话内容，也不会向主题预览夹具同步这些数据。
- 最近发现的项目与会话列表、全局会话图标开关和每个主题的手动图标分配保存在本机 `project-icons.json`。它们不属于主题配置或素材库配置。
- `.cdstheme` 只允许分享主题、启用的素材库、素材库启用状态和图标优先级；`.cdsicons` 只允许分享一个自定义素材库及其图标。两种格式都不得包含项目或会话 ID、显示名称、会话标题、路径、最近发现缓存、全局开关或手动分配。
- 主题复制可以在本机复制项目与会话图标设置；主题分享导入必须重新生成主题、素材库和图标 ID，并把两类手动分配保持为空。

## 预览数据要求

侧边栏预览使用 `src/renderer/src/preview-home.ts` 中的固定示例快照。修改该快照时必须同步更新测试中的完整允许列表，确保评审能够识别新增名称。布局测试必须继续覆盖虚构团队标识，禁止改成本机账号或团队名称。

## README 截图要求

- README 截图必须来自使用隔离应用数据目录启动的真实 Electron Studio 页面，不得使用设计稿或与实际软件不一致的模拟界面。
- 截图窗口固定为 `1480×920`，并激活对应语言的 Studio 界面和预览内容。
- `README.md` 使用英文 Studio 与英文预览内容，`README.zh-CN.md` 使用简体中文 Studio 与中文预览内容。
- 临时截图必须先保存在已忽略目录中。只有人工确认画面仅包含当前公开仓库名或明显虚构的数据后，才能复制到 `docs/` 并提交。

## 提交前检查

1. 检查 `git diff` 和分享包测试夹具中的项目、任务、账号、团队、邮箱和本机路径；只允许明显虚构的隐私断言数据。
2. 检查新增图片及日志，确认没有真实环境信息；双语 README 截图还要确认界面语言与预览内容语言一致。
3. 运行 `npm test -- --run tests/preview-layout.test.ts`，确认示例数据允许列表未被绕过。

违反以上任一规则时不得提交、发布或打包。
